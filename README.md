# ⚔️ MDS Scripts

<img src="./logo_mds_scripts.svg" width="180">

Scripts para **Tribal Wars** desenvolvidos por **MDS**  
Focados em automação, eficiência e vantagem estratégica.

---

## 🚀 Funcionalidades

- ⚔️ Automação de ataques
- 🎯 Fakes inteligentes
- 🧠 Scripts otimizados para performance
- 🔄 Compatível com Tampermonkey

---

## 📦 Instalação

1. Instalar o Tampermonkey  
2. Adicionar o loader/script  
3. Garantir que está ativo no jogo  

---

## 🧠 Como usar

- Abre o Tribal Wars  
- Vai ao ecrã correspondente (mapa / ataque)  
- O script ativa automaticamente
